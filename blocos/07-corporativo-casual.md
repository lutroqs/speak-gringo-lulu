# Corporativo x casual {#registro}

A mesma ideia muda de forma conforme o ambiente. Use a coluna da esquerda no trabalho, com clientes e desconhecidos; a da direita, com amigos e família.

| Situação | Corporativo | Casual |
| --- | --- | --- |
| Cumprimentar | Good morning, how are you? | Hey, what's up? |
| Despedir-se | Have a great weekend. | See ya! / Later! |
| Pedir algo | Could you please send me the file? | Can you send me that? |
| Agradecer | Thank you, I really appreciate it. | Thanks a lot! / You're the best! |
| Pedir desculpas | I apologize for the delay. | Sorry I'm late! / My bad. |
| Discordar | I see your point, but I have a different view. | Nah, I don't think so. |
| Não saber | I'll look into it and get back to you. | No idea, let me check. |
| Atraso | I'm running a few minutes late. | I'm gonna be late, sorry! |
| Dizer não | Unfortunately, I won't be able to make it. | Can't make it, sorry! |
| Interromper | Sorry to interrupt, may I add something? | Wait, wait — can I say something? |
| Pedir para repetir | Could you repeat that, please? | Sorry, what? / Come again? |
| Concordar | That makes sense. I agree. | Totally! / For sure! |
| Elogiar | Great job on the presentation. | You killed it! |
| Pedir ajuda | Would you mind giving me a hand with this? | Can you help me out? |
| Encerrar conversa | I'll let you go — thanks for your time. | Okay, gotta run! |
| Email: abertura | Dear Mr. Smith, / Hi Mark, | Hey! |
| Email: fechamento | Best regards, / Kind regards, | Cheers, / Talk soon! |
