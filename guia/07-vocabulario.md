# Vocabulário completo por tema {#vocabulario}

Cada tema tem as palavras mais úteis e uma frase real. Nas aulas, cada tema vira uma aula própria com as 14 etapas e 20 flashcards.

| Tema | Palavras-chave (tradução) | Frase real |
| --- | --- | --- |
| Vida diária | wake up (acordar), commute (trajeto até o trabalho), chores (tarefas de casa), errands (pendências na rua), nap (cochilo), schedule (agenda) | *I run errands after work.* (Resolvo pendências depois do trabalho.) |
| Casa | rent (aluguel), landlord (dono do imóvel), lease (contrato), utilities (contas de luz e água), laundry (roupa para lavar), mess (bagunça) | *The rent includes utilities.* (O aluguel inclui as contas.) |
| Mercado | groceries (compras), aisle (corredor), deal (oferta), brand (marca), expiration date (validade), receipt (nota) | *Check the expiration date.* (Confira a validade.) |
| Cinema | plot (enredo), cast (elenco), director (diretor), sequel (continuação), trailer (trailer), review (crítica) | *The cast is amazing, but the plot is weak.* (O elenco é ótimo, mas o enredo é fraco.) |
| Livros | novel (romance), author (autor), chapter (capítulo), bookstore (livraria), library (biblioteca), plot twist (reviravolta) | *I read a chapter every night.* (Leio um capítulo toda noite.) |
| Músicas | song (música), lyrics (letra), album (álbum), singer (cantor), band (banda), chorus (refrão), beat (batida) | *I can't get this song out of my head.* (Não consigo tirar essa música da cabeça.) |
| Esportes | match / game (partida), team (time), score (placar), referee (juiz), coach (treinador), tie (empate) | *The game ended in a tie.* (O jogo terminou empatado.) |
| Viagens | trip (viagem), luggage (bagagem), itinerary (roteiro), sightseeing (passeio turístico), currency (moeda), jet lag (fuso) | *I have terrible jet lag.* (Estou com um jet lag terrível.) |
| Tecnologia | device (aparelho), app (aplicativo), update (atualização), password (senha), download / upload, cloud (nuvem) | *Don't forget to update the app.* (Não esqueça de atualizar o app.) |
| Negócios | stakeholder (parte interessada), deadline (prazo), deliverable (entrega), KPI (indicador), revenue (receita), client (cliente) | *What's the deadline for this deliverable?* (Qual o prazo desta entrega?) |
| Finanças | budget (orçamento), cash flow (fluxo de caixa), forecast (previsão), loan (empréstimo), interest rate (taxa de juros), savings (economias) | *We're over budget this quarter.* (Estamos acima do orçamento neste trimestre.) |
| Contabilidade | balance sheet (balanço), income statement (DRE), ledger (razão), accrual (provisão), payable / receivable (a pagar / a receber), audit (auditoria) | *The audit starts next week.* (A auditoria começa semana que vem.) |
| Programação | code (código), bug (erro), debug (depurar), loop (laço), function (função), repository (repositório), deploy (publicar) | *I fixed the bug and deployed the code.* (Corrigi o bug e publiquei o código.) |
| Python | variable, list, dictionary, DataFrame, import, library, indentation (indentação), error message | *Import pandas and load the CSV.* (Importe o pandas e carregue o CSV.) |
| Power BI | dashboard, report, slicer (segmentação), measure (medida), DAX, data model, refresh (atualizar) | *The dashboard refreshes every morning.* (O painel atualiza toda manhã.) |
| Excel | spreadsheet (planilha), cell (célula), formula, pivot table (tabela dinâmica), XLOOKUP, filter, sort (classificar) | *Use a pivot table to summarize the data.* (Use uma tabela dinâmica para resumir os dados.) |
| Internet | website, link, browser (navegador), search (busca), Wi-Fi, connection, offline | *The connection is really slow today.* (A conexão está muito lenta hoje.) |
| Redes sociais | post, follower (seguidor), like, share (compartilhar), story, DM (mensagem direta), trending (em alta) | *She went viral last week.* (Ela viralizou semana passada.) |
| Relacionamentos | boyfriend / girlfriend, partner (parceiro), crush (paquera), date (encontro), break up (terminar), get along (se dar bem) | *We get along really well.* (A gente se dá muito bem.) |
| Saúde | appointment (consulta), prescription (receita), pharmacy (farmácia), symptoms (sintomas), headache (dor de cabeça), insurance (plano de saúde) | *I need to make a doctor's appointment.* (Preciso marcar uma consulta.) |
