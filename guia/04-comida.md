| beef | bíf | carne bovina | Is this beef or pork? (Isso é carne de boi ou de porco?) |

## Restaurantes

| Inglês | Pronúncia | Tradução |
| --- | --- | --- |
| table for two | TÊI-bou fór tchú | mesa para dois |
| menu | MÉ-niu | cardápio |
| appetizer / starter | É-pe-tái-zâr / STÁR-târ | entrada |
| main course / entrée (EUA) | mêin córs / ÓN-trêi | prato principal |
| dessert | di-ZÂRT | sobremesa |
| the check (EUA) / the bill (Reino Unido) | dhe tchék / dhe bil | a conta |
| tip | tip | gorjeta |
| to go / takeaway | tchu GÔU / TÊIK-a-uêi | para viagem |

**Frases reais:**

- *Hi, do you have a table for two?* (Oi, vocês têm mesa para dois?)
- *Could we see the menu, please?* (Podemos ver o cardápio?)
- *I'll have the chicken, please.* (Vou querer o frango.)
- *Could we get the check, please?* (Pode trazer a conta?)

**Pegadinha cultural:** nos EUA a gorjeta é esperada e costuma ficar entre 15% e 20%. No Reino Unido, verifique se o *service charge* já está incluído na conta.

## Fast food

| Inglês | Pronúncia | Tradução |
| --- | --- | --- |
| burger / cheeseburger | BÂR-gâr | hambúrguer |
| fries | fráiz | batata frita |
| combo / meal | KÓM-bou / míl | combo / lanche completo |
| refill | RÍ-fil | refil |
| drive-thru | DRÁIV-thru | drive-thru |
| for here or to go? | fór RÍR ór tchu GÔU | para comer aqui ou levar? |

**Diálogo rápido:**

> **Attendant:** Hi, what can I get for you?
> **You:** Can I get a number three with a Coke, please?
> **Attendant:** Sure. For here or to go?
> **You:** To go, please.
> **Attendant:** That'll be $11.50.

*(Atendente: Oi, o que vai ser? / Você: Pode ser um número três com Coca? / Atendente: Claro. Para comer aqui ou levar? / Você: Para levar. / Atendente: Dá 11,50 dólares.)*
